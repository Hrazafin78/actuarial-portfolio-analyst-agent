# Diagnostics de qualité locaux

Les fichiers JSON présents sont des résultats locaux conservés, pas des exemples
publics ni des résultats de référence. `validate_quality.py` écrit ici
`quality_report.json`. `quality_report_initial.json`, lorsqu’il est présent,
correspond à un ancien résultat conservé lors du rangement du projet.

Les contenus sont exclus des nouveaux ajouts Git, sauf ce fichier. Les PDF générés
dans Streamlit sont téléchargés par l’utilisateur et ne sont pas enregistrés
automatiquement dans ce dossier. Vérifier leur confidentialité avant partage.
