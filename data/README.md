# Données locales

Ce dossier accueille les données de travail, notamment `portefeuille.csv` pour le
script de validation indépendant. L’application importe les fichiers choisis par
l’utilisateur sans dépendre de ce chemin.

Aucun jeu de données n’est fourni par cette documentation. Les contenus de ce
dossier sont exclus des nouveaux ajouts Git, sauf ce fichier. Une exclusion ne
retire pas les données déjà suivies ou présentes dans l’historique.
